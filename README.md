# 中文笔记 RAG 检索评测台

纯静态、零后端的中文笔记 RAG 检索评测演示页。打开即用，断网可玩。

**在线访问**：页面发布后此处更新网址（GitHub Pages）。

## 它是什么

- 856 个中文笔记块（Obsidian 导出、已做身份脱敏）为检索库
- 10 道预置评测题：A 组 8 道原词命中型 + B 组 2 道语义改写型（题面故意不出现目标笔记关键词，是防「字面分压死语义」的探针）
- 语义分：离线用 bge/dmea 类 embedding 模型对每块与每题实算的余弦值，打包进 `data.js`（向量本体不出本机，页面不做语义在线计算）
- 字面分：浏览器内实时计算（BM25 形式 IDF + 词频饱和 + 宽度惩罚），公式与参考实现一致
- 注入攻击演示：开关打开后索引里多 7 个带真向量的投毒块；防御档按 R1/R5 规则剔块（这两条规则为本演示新增，参考实现没有）
- 一致性自检：浏览器排出的 top-3 与打包时参考实现 `search()` 逐题比对，30/30 一致
- 「换我的语料」：粘贴的文本只留在页面内存，不写 localStorage、不发往任何服务器

## 运行

无依赖、无构建：

```
# 直接双击 index.html 即可；或任意静态服务器：
python -m http.server 8000
```

## 目录

```
index.html   页面骨架
app.js       检索/评分/攻防/评测渲染逻辑
data.js      语料块 + 离线余弦 + 攻防期望值（打包产物，勿手改）
styles.css   设计系统（light/dark 跟随系统）
```

## 口径说明（报告纪律）

- 报分数时拆开报：A 组 8/8、B 组 0/2，合起来 8/10——B 组 0/2 是探针设计使然，不是调参失误
- 干净态/投毒态的期望值由参考实现 `search()` 原样算出；防御态验证的是排名引擎一致，R1/R5 规则本身不在参考实现里
- 自由输入通道是字面腿近似（2-gram + 英文标识符正则），无语义分，与预置题不可同表比较
